[Loading Screen Gold: A Tip in 200 Characters](https://make.fun/c/u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270).

A loading-screen tip for stressed developers and AI coding agents: the bug lives in the file you swore you'd never touch, written by a past you who swore they'd document it.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> Tip: the bug you're hunting lives in the file you swore you'd never touch, written by a past you who swore they'd document it. Go touch it. Your weekend is waiting.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
